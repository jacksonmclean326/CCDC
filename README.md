# BYU CCDC Tryout Prep

This is a public-safe GitHub Pages bundle for the 2026 BYU CCDC tryout environment.

Included:

- cheatsheet.html — commands for Ubuntu 18.04, Rocky Linux 9.6, Windows Server 2016, VyOS 2025.11, Splunk Enterprise 10.0.2, and service verification.
- prompt.html — initial AI-agent prompt with competition boundaries.
- quick-reference.html — scoring, rules, services, accounts, opening priorities, and submission requirements.
- topology.html — generic topology using the x team-number placeholder.

Intentionally excluded:

- Passwords and credentials
- Team number and resolved IP addresses
- Operational scripts
- Inject responses or inject templates
- Incident-response notes, screenshots, and logs

To publish, place these files in a public repository and enable GitHub Pages for the branch/folder containing index.html. Confirm every page loads without signing in before the competition.
