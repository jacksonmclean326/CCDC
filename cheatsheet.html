Command cheatsheet

Replace angle-bracket placeholders before running commands. Run commands only against your assigned environment.

Operational caution: Start with read-only checks. Confirm scope before changing users, firewall rules, routes, services, or files. Never scan or access another team.

Cross-platform service verification

Use your assigned public address when validating scored services. These examples are for your own hosts only.

curl -I --max-time 10 http://<public-ip>/Check HTTP headers and response.
curl -k -I --max-time 10 https://<public-ip>/Check HTTPS headers; ignore certificate validation.
dig @<dns-server> <domain>Ask a specific DNS server for a full answer.
dig +short <domain>Show only the resolved address or record.
nc -vz -w 5 <public-ip> 21Test TCP port 21 (FTP).
nc -vz -w 5 <public-ip> 22Test TCP port 22 (SSH).
nc -vz -w 5 <public-ip> 25Test TCP port 25 (SMTP).
nc -vz -w 5 <public-ip> 110Test TCP port 110 (POP3).
ssh -o ConnectTimeout=5 <user>@<public-ip>Try SSH with a five-second connection timeout.
openssl s_client -connect <public-ip>:<port> -servername <hostname>Inspect a TLS connection and certificate.
Test-NetConnection <public-ip> -Port 22Test SSH TCP reachability from Windows.
Test-NetConnection <public-ip> -Port 110Test POP3 TCP reachability from Windows.
Invoke-WebRequest -UseBasicParsing http://<public-ip>/Request a web page from PowerShell.

Ubuntu Server 18.04

Identity and access

whoamiPrint the current username.
idShow current user and group IDs.
getent passwdList account records from configured sources.
getent groupList group records from configured sources.
sudo passwd <username>Set that account's password.
sudo chage -l <username>Show password aging and expiry settings.
last -F | head -30Show the 30 most recent login sessions.
lastlogShow each account's most recent login.

Network and services

ip addrShow interface addresses and status.
ip routeShow the routing table.
ss -tulpnList listening TCP/UDP sockets and processes.
sudo systemctl --type=service --state=runningList currently running services.
sudo systemctl status <service>Inspect a service's state and recent output.
sudo systemctl restart <service>Restart a service; this interrupts it briefly.
sudo systemctl list-unit-files --state=enabledList units configured to start automatically.

Logs and persistence

sudo journalctl -p warning..alert -bShow warning-or-higher logs from this boot.
sudo journalctl -u <service> --since "2 hours ago"Show a service's logs from the last two hours.
sudo tail -n 100 /var/log/auth.logShow the latest authentication log entries.
sudo find /etc/cron* -maxdepth 2 -type f -lsList scheduled-job files under cron directories.
crontab -lList the current user's scheduled jobs.
sudo ls -la /etc/ssh/List SSH server configuration files.

Firewall and packages

sudo ufw status verboseShow UFW firewall status and rules.
sudo iptables -SPrint firewall rules in command form.
sudo iptables -L -n -vList firewall rules with counters and numeric addresses.
apt list --upgradableList packages with available upgrades.
dpkg -l | lessPage through installed package details.
sudo ss -lntupList listening TCP/UDP ports and owning processes.

If a service is managed by systemd, inspect its status and logs before restarting it. Preserve required content and dependencies.

Configuration workflow

configureEnter configuration mode.
Make one deliberate changeChange only the intended setting in configuration mode.
compareReview pending changes before applying them.
commit-confirm 5Apply changes provisionally; auto-revert after five minutes unless confirmed.
confirmKeep the provisional changes and cancel rollback.
saveSave the active configuration to disk.
exitLeave configuration mode.

Safety reminders

show configuration commands | match firewallFind firewall settings in the active configuration.
show configuration commands | match natFind NAT settings in the active configuration.
discardDrop pending, uncommitted configuration changes.
exitLeave configuration mode.

Keep the assigned public addresses and required NAT behavior intact. Do not create rules that only allow the scoring engine or block other source IPs.

Splunk Enterprise 10.0.2

Index and sourcetype names may vary. Start by discovering what your own indexer receives.

index=* | stats count latest(_time) as latest by index sourcetype host | sort - countDiscover indexes, sources, hosts, event counts, and latest event times.
index=* earliest=-24h | stats count by host source sourcetype | sort - countSummarize the last 24 hours of data by host and source.
index=* earliest=-24h (action=failure OR "failed password" OR "authentication failure" OR EventCode=4625) | stats count values(user) as users values(src_ip) as source_ips by host | sort - countCount likely failed logons and show related users and source IPs.
index=* (EventCode=4624 OR EventCode=4625) | stats count by host EventCode user src_ip | sort - countCompare Windows successful and failed logons by host and user.
index=* (EventCode=4672 OR "special privileges assigned") | table _time host user src_ip EventCode Message | sort - _timeReview recent privileged logon events.
index=* (EventCode=4688 OR sourcetype=*powershell* OR "New Process") | table _time host user ParentImage NewProcessName CommandLine Message | sort - _timeReview process-creation and PowerShell events.
index=* ("Failed password" OR "Accepted password" OR "Invalid user") | table _time host user src_ip source _raw | sort - _timeReview Linux SSH failures, successes, and invalid-user attempts.
index=_internal earliest=-1h | stats count by host sourcetype source | sort - countCheck recent Splunk internal data by host and source.

Do not disable forwarding to the Black Team-controlled indexer. Use your own indexer to improve visibility where permitted.
