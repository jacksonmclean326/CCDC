Command cheatsheet

Replace angle-bracket placeholders before running commands. Run commands only against your assigned environment.

Operational caution: Start with read-only checks. Confirm scope before changing users, firewall rules, routes, services, or files. Never scan or access another team.

Cross-platform service verification

Use your assigned public address when validating scored services. These examples are for your own hosts only.

# HTTP/HTTPS
curl -I --max-time 10 http://<public-ip>/
curl -k -I --max-time 10 https://<public-ip>/

# DNS
dig @<dns-server> <domain>
dig +short <domain>

# TCP reachability
nc -vz -w 5 <public-ip> 21
nc -vz -w 5 <public-ip> 22
nc -vz -w 5 <public-ip> 25
nc -vz -w 5 <public-ip> 110

# SSH
ssh -o ConnectTimeout=5 <user>@<public-ip>

# TLS / POP3S / HTTPS troubleshooting
openssl s_client -connect <public-ip>:<port> -servername <hostname>

# Windows equivalents
Test-NetConnection <public-ip> -Port 22
Test-NetConnection <public-ip> -Port 110
Invoke-WebRequest -UseBasicParsing http://<public-ip>/

Splunk Enterprise 10.0.2

Index and sourcetype names may vary. Start by discovering what your own indexer receives.

# Discover data coverage
index=*
| stats count latest(_time) as latest by index sourcetype host
| sort - count

# Recent events by host and source
index=* earliest=-24h
| stats count by host source sourcetype
| sort - count

# Failed authentication activity
index=* earliest=-24h (action=failure OR "failed password" OR "authentication failure" OR EventCode=4625)
| stats count values(user) as users values(src_ip) as source_ips by host
| sort - count

# Windows successful and failed logons
index=* (EventCode=4624 OR EventCode=4625)
| stats count by host EventCode user src_ip
| sort - count

# Privileged logons
index=* (EventCode=4672 OR "special privileges assigned")
| table _time host user src_ip EventCode Message
| sort - _time

# Process creation / PowerShell activity
index=* (EventCode=4688 OR sourcetype=*powershell* OR "New Process")
| table _time host user ParentImage NewProcessName CommandLine Message
| sort - _time

# Linux SSH activity
index=* ("Failed password" OR "Accepted password" OR "Invalid user")
| table _time host user src_ip source _raw
| sort - _time

# Splunk health
index=_internal earliest=-1h
| stats count by host sourcetype source
| sort - count

Do not disable forwarding to the Black Team-controlled indexer. Use your own indexer to improve visibility where permitted.

Useful shell patterns

# Search recent authentication records
sudo grep -iE "fail|invalid|accepted|sudo" /var/log/auth.log /var/log/secure 2>/dev/null | tail -100

# Find listening services and owning processes
sudo ss -lntup

# Find recently modified files in common configuration areas
sudo find /etc /var/www -xdev -type f -mmin -180 -ls 2>/dev/null

# PowerShell: save a small command result for later review
Get-NetTCPConnection -State Listen | Out-File .\listening-ports.txt
